# AI Prompt History

## Purpose

This file records the main categories of AI assistance used during development.
It is a summary, not a complete verbatim transcript of every conversation.

## Development prompt topics

1. Plan a synthetic insurance fraud detection project from the challenge requirements.
2. Design a Python data generator for claimants, providers, policies, incidents, claims, invoices, payments, and relationship edges.
3. Add deterministic identifiers, a fixed random seed, and reproducibility checks.
4. Design data validation for primary keys, references, dates, financial amounts, and lifecycle statuses.
5. Create CSV and JSON exports for generated datasets.
6. Build a SQLite database from generated records and verify database integrity.
7. Implement explainable rule-based claim risk scoring using operational records.
8. Keep synthetic ground-truth labels separate from risk-scoring inputs.
9. Evaluate risk scores using confusion-matrix counts, precision, recall, and F1 score.
10. Create negative-scenario tests for invalid references, excessive payments, duplicate invoices, missing relationship edges, and benign shared addresses.
11. Generate an investigation report with risk evidence and supporting operational details.
12. Review and align the README, SQL schema, data model, and data dictionary with the implementation.
13. Prepare the project for a reproducible public GitHub submission.

## Verification and limitations

AI assistance was used for planning, coding guidance, debugging, tests, and documentation.
The project owner should review the code, run the tests, and be prepared to explain the design decisions and limitations.

This file summarizes prompt topics and does not claim to be a complete export of the original prompts or AI responses.
